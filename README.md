# Pengembangan Perangkat Lunak Bioinformatika

Website praktikum untuk mata kuliah Pengembangan Perangkat Lunak Bioinformatika, BIF-IPB.

## Teknologi

- HTML semantik
- CSS responsif
- JavaScript tanpa framework

## Menjalankan secara lokal

Buka `index.html` di peramban. Website ini tidak memerlukan proses build atau instalasi dependensi.
