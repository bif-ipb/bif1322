MATERI / PERTEMUAN 06-11

Pembangunan Aplikasi Berbasis Rancangan

Mengimplementasikan aplikasi secara bertahap berdasarkan SKPL, arsitektur, pipeline, dan rancangan antarmuka yang telah disusun.

Tujuan Praktikum 6-11

  1. Menyiapkan lingkungan dan repository proyek untuk pembangunan aplikasi.
  2. Mengimplementasikan fitur aplikasi berdasarkan Dokumen SKPL, arsitektur, pipeline, serta rancangan interface yang telah dibuat.
  3. Mengelola pekerjaan pembangunan melalui GitHub Issue dan GitHub Project.
  4. Melaporkan progres pembangunan aplikasi secara berkala, termasuk capaian, kendala, dan rencana pekerjaan berikutnya.

Pengantar praktikum

Pada pertemuan sebelumnya, setiap kelompok telah menyusun Dokumen SKPL, rancangan arsitektur dan pipeline, serta wireframe dan desain high-fidelity. Artefak tersebut menjelaskan kebutuhan sistem, alur data dan proses, serta tampilan yang akan digunakan oleh pengguna. Pada tahap ini, seluruh rancangan tersebut digunakan sebagai acuan untuk membangun aplikasi.

Pembangunan aplikasi dilakukan secara bertahap selama Pertemuan 6-11. Kelompok tidak perlu menyelesaikan semua fitur pada minggu pertama. Mulailah dari fitur dan alur pengguna utama, kemudian kembangkan fitur berikutnya sesuai prioritas kebutuhan pada SKPL. Setiap keputusan implementasi perlu tetap konsisten dengan arsitektur, pipeline, dan desain interface yang telah dibuat.

Pekerjaan pembangunan dikelola melalui repository, GitHub Issue, dan GitHub Project kelompok. Setiap minggu, kelompok mengirimkan progress report yang memuat capaian, bukti implementasi, kendala, dan rencana pekerjaan berikutnya. Asisten praktikum membuka sesi konsultasi daring bagi kelompok yang memerlukan diskusi atau pendampingan.

Hasil pembangunan pada tahap ini akan digunakan pada Pertemuan 12-13 untuk pengujian berdasarkan kebutuhan dan acceptance criteria pada SKPL. Selanjutnya, hasil satu iterasi pembangunan dan pengujian akan disajikan pada presentasi akhir di Pertemuan 14.
