BIF-IPB / PRAKTIKUM

Pengembangan Perangkat Lunak Bioinformatika

Portal materi, proyek, dan referensi untuk praktikum pengembangan perangkat lunak berbasis permasalahan bioinformatika.

Tentang praktikum

Praktikum ini melatih proses pengembangan perangkat lunak secara terstruktur: memahami kebutuhan pengguna, merancang solusi, menyusun rencana pengembangan, dan mengelola artefak proyek. Kasus yang digunakan berangkat dari kebutuhan riset bioinformatika.

Fokus kerja

Setiap kelompok membangun dokumentasi dan solusi proyek secara bertahap, bukan hanya mengumpulkan kode akhir.

Materi praktikum

Materi disusun mengikuti tahapan pengembangan proyek. Tautan modul dan instruksi akan ditambahkan pada setiap pertemuan.

Proyek kelompok

Proyek dimulai dari penetapan ruang lingkup dan kebutuhan. Setiap keluaran harus dapat ditelusuri kembali ke masalah bioinformatika yang ingin diselesaikan.

  1. Definisikan masalahRumuskan konteks, pemangku kepentingan, dan kebutuhan utama.
  2. Susun proposalBangun argumen solusi, ruang lingkup, serta luaran proyek.
  3. Rencanakan pengembanganTetapkan proses, jadwal, risiko, dan pembagian kerja tim.

Penilaian

Komponen dan bobot penilaian akan dipublikasikan pada halaman ini. Gunakan umpan balik setiap pertemuan sebagai dasar perbaikan artefak proyek.

Tools dan referensi

  • Git untuk pelacakan perubahan dan kolaborasi kode.
  • GitHub untuk repository, issue, dan dokumentasi proyek.
  • Visual Studio Code sebagai salah satu editor yang dapat digunakan.

Kalender

Jadwal pertemuan, tenggat tugas, dan agenda penting akan diperbarui di sini.

Tim praktikum

Informasi pengajar dan asisten praktikum akan ditambahkan setelah dikonfirmasi.
