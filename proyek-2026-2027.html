PROJECT BRIEF

Variant Calling dan GWAS

Studi kasus tanaman bawang putih (garlic) untuk proyek kelompok mata kuliah Pembangunan Perangkat Lunak Bioinformatika.

8 kelompok developer2 paket kerja14 pertemuan

OVERVIEW PAKET PROJECT

Ruang kerja proyek

Kelompok mengembangkan solusi perangkat lunak untuk mendukung studi kasus analisis genomik tanaman bawang putih. Paket kerja terbagi menjadi Variant Calling dan GWAS; detail kebutuhan, data, alur pengguna, serta batas lingkup akan disepakati bersama sebelum implementasi.

OUTPUT

Luaran proyek

Sebuah pipeline terintegrasi untuk Variant Calling dan GWAS, disertai repositori, dokumentasi, dan artefak pengembangan kelompok.
